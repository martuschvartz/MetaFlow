# Tech Stack

## Frontend & Core Framework
- **Framework:** Next.js (App Router)
- **Library:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS (recomendado para iteración rápida de UI)
- **Componentes UI:** shadcn/ui o componentes nativos de Tailwind (ideal para sliders, checkboxes y modales rápidos).

## Deployment & Hosting
- **Plataforma:** Vercel

## Future Architecture (Post-MVP)
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security para separar perfiles de psicólogos y jugadoras).
